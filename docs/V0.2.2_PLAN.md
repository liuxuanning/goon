# Goon V0.2.2 — 单用户模型调用修复

产品定位：产品经理个人 AI 商业机会发现工作台，不采用审核员/双人审批作为模型分析前置条件。

本次范围：
- /api/analyze/demands 不再经过审核员令牌门禁。
- 前端分析按钮不发送审核员令牌。
- 豆包密钥、Base URL、Model ID 仅由服务器 .env / 服务环境读取。
- 增加 node server.mjs --test-ark 真实连通性检查；仅输出模型标识、耗时、Token用量，不输出密钥和响应原文，不写业务数据库。
- 保留机会审核类接口现有保护，不在本次扩大变更范围；后续单用户化时逐步移除双人审核业务模型。
- 不向浏览器暴露 ARK_API_KEY，不把 .env 提交 Git。

验收：
1. 前后端语法检查通过。
2. 离线测试静态确认模型分析路由独立于审核员令牌。
3. 服务器 CLI 真实豆包调用成功。
4. 通过网页按钮发起真实分析，结构化结果成功写入 SQLite。
